API Integration

Integrate the Arabic STT Platform into your applications using our simple REST API.

Upload File for Transcription
curl -X POST http://localhost:5000/api/transcribe \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@audio.mp3" \
  -F "model_size=medium" \
  -F "language=ar" \
  -F "output_formats=txt" \
  -F "output_formats=srt"
Check Status
curl -X GET http://localhost:5000/status/JOB_ID
Download Results
curl -X GET http://localhost:5000/download/JOB_ID/txt
